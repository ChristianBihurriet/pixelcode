# Miniweb HTML y CSS · 1.º DAM

📚 **Material didáctico | CFGS Desarrollo de Aplicaciones Multiplataforma**

**Curso:** 1.º DAM  
**Módulo:** Lenguajes de Marcas y Sistemas de Gestión de Información  
**Profesor y autor:** Christian Bihurriet  
**Centro educativo:** CESUR

Repositorio de material docente elaborado para la enseñanza de HTML5 y CSS3 en
el Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones
Multiplataforma (DAM). Incluye una miniweb con ejemplos sencillos y progresivos,
diseñados para estudiantes que están aprendiendo a crear y dar estilo a páginas
web.

Este proyecto permite practicar la estructura semántica de HTML, la navegación
entre varias páginas, las rutas relativas, los formularios y la aplicación de
estilos mediante una hoja CSS compartida.

## PixelCode

Miniweb estática de una empresa ficticia de desarrollo de software. El proyecto
sirve como ejemplo de HTML5 y CSS3 básico para alumnado de 1.º de DAM.

## Estructura

```text
pixelcode/
├── index.html
├── nosotros.html
├── contacto.html
├── estilos.css
├── img/
│   ├── .gitkeep
│   └── equipo.jpg (se añadirá posteriormente)
└── README.md
```

## Cómo abrir la web

Abre el archivo `index.html` en un navegador. No es necesario instalar nada.
Desde el menú superior se puede navegar por las tres páginas.

## HTML y CSS

HTML organiza el contenido y le da significado mediante encabezados, secciones,
enlaces, imágenes y formularios. CSS modifica su presentación: colores,
espacios, bordes, tamaños y alineación.

## Propuestas para practicar

1. Cambia el color de fondo de la cabecera en `estilos.css`.
2. Modifica el grosor o el color del borde de `.imagen-equipo`.
3. Añade un cuarto servicio en `index.html` reutilizando la clase `tarjeta-servicio`.
